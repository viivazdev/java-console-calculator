# java-console-calculator

A simple console-based calculator built using Java.

This project was created for **Java practice and understanding fundamental programming concepts**. It is not intended to be a production-level calculator.

## Purpose

The main purpose of this project is to practice how different Java fundamentals work together inside a small working application.

Instead of practicing every concept separately, this calculator combines input handling, operators, conditions, loops, and program flow in one project.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Menu-driven console interface
* Perform multiple calculations without restarting the program
* Clear/reset the current calculation
* Exit option to close the calculator
* Basic handling of user choices

## Java Concepts Practiced

### 1. Variables and Data Types

Variables are used to store numbers, user choices, and calculation results.

### 2. Scanner Class

`Scanner` is used to take input from the user through the console.

### 3. Arithmetic Operators

The calculator uses Java arithmetic operators:

* `+` Addition
* `-` Subtraction
* `*` Multiplication
* `/` Division

### 4. Conditional Statements

Conditions are used to control what the program should do depending on the user's input.

### 5. Switch Statement

A `switch` statement is used to select the calculator operation based on the menu option chosen by the user.

### 6. Loops

A loop keeps the calculator running so the user can perform multiple calculations without restarting the program.

### 7. User Input

The program accepts numbers and operation choices directly from the console.

### 8. Program Flow

The project helped practice controlling how a Java program moves between:

* Menu
* User input
* Calculation
* Result
* Reset
* Exit

## Key Learning Points

Through this project I practiced:

* Taking console input in Java
* Performing calculations using operators
* Using conditions to make decisions
* Using `switch` for menu-based programs
* Using loops to keep a program running
* Handling multiple user actions in a single program
* Creating an exit condition
* Resetting calculator values without restarting the program
* Understanding how multiple Java concepts work together

## How to Run

Make sure Java is installed on your system.

Compile the program:

```bash
javac Calculator.java
```

Run the program:

```bash
java Calculator
```

## Example

```text
===== JAVA CALCULATOR =====
1. Calculate
2. Clear
3. Exit
Enter your choice:
```
